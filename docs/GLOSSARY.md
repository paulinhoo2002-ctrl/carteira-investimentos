# Glossary

## A
**ADR** — Architecture Decision Record. Documented architectural choices with context and consequences.

**Amortização** — Return of principal capital in fixed income. Reduces cost basis, not income.

**API** — Application Programming Interface. Contract between client and server.

**Asset** — Financial instrument held in portfolio (stock, FII, ETF, bond, crypto, etc.).

**Ativo** — Portuguese for Asset.

**Autenticação** — Authentication. Verification of identity (Firebase Auth).

**Autorização** — Authorization. Permission to access resources (Firestore rules).

---

## B
**B3** — Brasil, Bolsa, Balcão. Brazilian stock exchange. Official data source.

**Backlog** — Prioritized list of work items.

**Backup** — Point-in-time copy of Firestore data + local IndexedDB.

**Benchmark** — Reference rate for fixed income valuation (CDI, IPCA, SELIC).

**BDR** — Brazilian Depositary Receipt. Foreign stock traded on B3.

**Branch** — Git branch. `main` = production, `feat/*` = features, `fix/*` = bugs.

**Build** — Compilation + bundling process (Vite).

**Bundle** — Output JavaScript/CSS files for deployment.

---

## C
**CAGR** — Compound Annual Growth Rate. Geometric mean return per year.

**Carteira** — Portfolio. Collection of assets.

**CDI** — Certificado de Depósito Interbancário. Brazilian interbank rate benchmark.

**CI/CD** — Continuous Integration / Continuous Deployment.

**CLS** — Cumulative Layout Shift. Core Web Vital metric.

**Commit** — Git commit. Snapshot of changes.

**Conventional Commits** — Standardized commit message format (`feat:`, `fix:`, etc.).

**Corretora** — Brokerage. Financial intermediary.

**CSP** — Content Security Policy. Browser security header.

**CTA** — Call to Action. Button/link prompting user action.

---

## D
**Dashboard** — Main screen showing portfolio overview.

**DCA** — Dollar Cost Averaging. Regular fixed-amount investments.

**DevOps** — Development + Operations practices.

**Dividendo** — Dividend. Profit distribution to shareholders.

**DRE** — Demonstração de Resultado do Exercício. Income statement.

**DRIP** — Dividend Reinvestment Plan. Automatic dividend reinvestment.

**DR** — Disaster Recovery. Plan to restore service after catastrophe.

---

## E
**E2E** — End-to-End. Tests simulating real user flows.

**ESM** — ECMAScript Modules. `import`/`export` syntax.

**ETF** — Exchange Traded Fund. Basket of assets traded as single ticker.

---

## F
**FII** — Fundo de Investimento Imobiliário. Brazilian REIT.

**Firestore** — Firebase NoSQL database.

**Flaky Test** — Test that passes/fails non-deterministically.

**Fork** — Copy of repository for independent development.

---

## G
**Git** — Distributed version control system.

**GitHub Actions** — CI/CD platform integrated with GitHub.

**Glossário** — Glossary. This document.

---

## H
**HSTS** — HTTP Strict Transport Security. Forces HTTPS.

**HTTPS** — HTTP Secure. TLS-encrypted HTTP.

---

## I
**IPCA** — Índice Nacional de Preços ao Consumidor Amplo. Brazilian inflation index.

**IR** — Imposto de Renda. Income tax.

**Invariante** — Invariant. Rule that must always hold (financial formulas).

---

## J
**JCP** — Juros sobre Capital Próprio. Interest on equity (taxable dividend-like).

**Juros** — Interest. Cost of borrowing / return on lending.

---

## K
**KPI** — Key Performance Indicator. Measurable metric.

---

## L
**LCI/LCA** — Letra de Crédito Imobiliário/Agro. Tax-exempt fixed income (PF).

**Legacy** — Old codebase version (pre-M862).

**Lint** — Static code analysis for errors/style.

**Lote** — Lot. Group of shares bought at same price/date.

---

## M
**Manifest** — PWA manifest.json. App metadata for installation.

**Mark-to-Market** — Valuation at current market prices.

**MCP** — Mission Control Panel. Internal term for admin interface.

**Merge** — Combine Git branches.

**Monte Carlo** — Simulation method using random sampling.

**MR** — Merge Request (GitHub: Pull Request).

---

## N
**NAV** — Net Asset Value. Fund value per share.

**NPM** — Node Package Manager.

---

## O
**OIDC** — OpenID Connect. Authentication protocol (Firebase uses it).

**Offline-First** — Architecture prioritizing offline functionality.

**OAuth** — Open Authorization. Delegated access protocol.

---

## P
**P0/P1/P2/P3** — Incident severity levels (Critical → Low).

**PAT** — Personal Access Token. GitHub API token.

**PWA** — Progressive Web App. Installable, offline-capable web app.

---

## Q
**QA** — Quality Assurance. Testing and validation.

**Quota** — Rate limit quota (Cloudflare, Firebase).

---

## R
**Renda Fixa** — Fixed Income. Bonds, CDs, Treasury.

**Renda Variável** — Variable Income. Stocks, FIIs, ETFs.

**REIT** — Real Estate Investment Trust (US equivalent of FII).

**Release** — Versioned deployment to production.

**Rendibilidade** — Return/Profitability percentage.

**Rollback** — Revert to previous version.

**RPO** — Recovery Point Objective. Max acceptable data loss.

**RTO** — Recovery Time Objective. Max acceptable downtime.

---

## S
**SBOM** — Software Bill of Materials. Component inventory (CycloneDX).

**SCD** — Split/Combination/Dividend. Corporate events.

**SELIC** — Sistema Especial de Liquidação e Custódia. Brazilian benchmark rate.

**Semantic Release** — Automated versioning from commit messages.

**SLA** — Service Level Agreement. Uptime/performance commitment.

**SRI** — Subresource Integrity. Hash verification for external resources.

**SSO** — Single Sign-On. One login for multiple systems.

**SW** — Service Worker. Background script for PWA.

**Synthetic Data** — Generated test data (not real user data).

---

## T
**TDD** — Test-Driven Development. Write tests first.

**Ticker** — Stock symbol (e.g., PETR4, HGLG11).

**TWR** — Time-Weighted Return. Portfolio return excluding cash flows.

---

## U
**UID** — User ID. Firebase unique identifier (`yaypxiiv7Ye7pwpDZ0nqhG3Yj7E3`).

**UAT** — User Acceptance Testing.

**Unrealized Gain/Loss** — Paper profit/loss not yet sold.

---

## V
**V84** — Visual regression test ID (asset detail screens).

**V250** — Service Worker version series.

**Vercel** — Hosting platform for frontend.

**Versionamento** — Versioning. Semantic versioning (MAJOR.MINOR.PATCH).

---

## W
**WAF** — Web Application Firewall (Cloudflare).

**WCAG** — Web Content Accessibility Guidelines.

**Webhook** — HTTP callback for events.

**Worktree** — Git linked working directory.

---

## X
**XIRR** — Extended Internal Rate of Return. IRR for irregular cash flows.

**XLSX** — Excel spreadsheet format. Used for B3/broker imports.

---

## Y
**YTD** — Year to Date. January 1 to current date.

**Yield** — Annual income / current price (dividend yield).

---
