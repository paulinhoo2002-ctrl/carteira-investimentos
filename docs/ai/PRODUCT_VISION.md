# Visão do produto

Carteira de Investimentos é um sistema pessoal de controle patrimonial de
longo prazo. O usuário registra compras, vendas e, opcionalmente, notas de
corretagem; o sistema busca preços públicos, descobre eventos de renda,
calcula posições, patrimônio, desempenho e reconciliações.

Princípios: custo recorrente obrigatório zero, dados portáteis, B3 como
reconciliação opcional, separação entre realizado e esperado e fluxo diário
simples. A interface deve ser legível em desktop 1366x768 e mobile 390x844.
