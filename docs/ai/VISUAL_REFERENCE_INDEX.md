# Public visual reference policy

This index contains no image inventory. Historical screenshots and their
machine-local provenance are not part of the public visual contract. The
current public design guidance is `VISUAL_CANON.md`; the reference directory's
`README.md` and `CANON_INDEX.md` define what may be published.

Private portfolio screenshots must remain local. An image can be added to the
public reference set only after proving it is synthetic, independently
public-safe, or explicitly approved for publication. Review provenance,
privacy, and asset contents before tracking it.
