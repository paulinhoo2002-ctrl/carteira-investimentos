# Lições aprendidas

- Raw state e fingerprint vencem texto de relatório em caso de divergência.
- Service Worker pode servir runtime antigo; validar origem, versão e cache.
- Snapshot date não é necessariamente valuation date.
- Compra não é aporte; venda não é retirada; provento esperado não é realizado.
- Cobertura parcial nunca deve aparecer como dado completo ou live.
- Falhas repetidas exigem diagnóstico e pivot, não retry cego.
- Stores derivados não podem alcançar autoridade de persistência financeira.
- XP/BTG só devem ser suportados após fixtures sanitizadas determinísticas.
