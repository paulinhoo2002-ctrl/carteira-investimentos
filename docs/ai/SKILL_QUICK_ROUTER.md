# Quick Skill Router

Use o menor conjunto confirmado localmente:

| Necessidade | Skill |
|---|---|
| Descobrir capacidade ausente | `find-skills` |
| Financeiro, persistência ou recovery | `doubt-driven-development` |
| Firebase, Auth, Firestore ou segurança cloud | `firebase-security-rules-auditor` |
| Sincronização local/cloud ou protected write | `firebase-security-rules-auditor` + `doubt-driven-development` |
| Implementação de UI de produto | `interface-design` |
| Nova direção visual | `frontend-design` |
| Polish visual final | `impeccable` |
| Acessibilidade, performance, responsividade e web quality | `web-quality-audit` |
| Automação e E2E browser | `browser-harness` + `playwright` |
| Diagnóstico DOM, console e rede | `browser-testing-with-devtools` |
| Tokens e componentes | `design-system` |
| Contexto grande | `caveman-compress` |
| Review final | `caveman-review` |
| Commit seletivo | `caveman-commit` |

`ui-ux-pro-max`, `brand`, `banner-design`, `slides` e `ui-styling` são sob
demanda. Nenhuma Skill autoriza escrita protegida, cloud, deploy ou dependência
paga.
