# Contrato do produto pessoal

O usuário mantém compras, vendas, transferências e correções. O sistema
calcula posições, preços públicos, performance e eventos esperados. B3 é
reconciliação opcional; eventos públicos não escrevem no ledger realizado.

MODE_A (`AUTO_DISCOVER_MANUAL_REALIZE`) permanece ativo. Auto-realização,
cloud write, sync financeiro e qualquer recuperação continuam desabilitados.

Patrimônio deve informar seu escopo: ativos listados, renda fixa e outros
componentes só entram no total quando há valor determinístico disponível.
