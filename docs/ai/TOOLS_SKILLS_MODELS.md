# Ferramentas, Skills e modelos

Skills úteis: `planning-with-files` para missões longas; `playwright` e
`browser-harness` para QA real; `deep-research`, `fact-checker` e
`source-tracker` para fontes; `mantis-architecture`, `mantis-structural-index`,
`mantis-threat-model`, `mantis-review`, `mantis-critic` e `mantis-report` para
arquitetura/segurança.

Descobrir disponibilidade antes de escolher modelo. Não tornar modelo,
provider pago ou credencial um bloqueador. Preferir esforço moderado e
execução econômica; revisão financeira exige raciocínio mais forte quando
disponível.
